# AnalogInstrumentMR v0.3.0-concept.2

Release date: 2026-09-27
Distribution: **GitHub source pre-release; APK not published**

## Release goal

This candidate extends the v0.3 signal environment into a playable modular
audio instrument. It adds ten audio-module kinds, device and theme-specific
operating sounds, the independent Superfine production theme, revised Quest
controller interaction, and an explicit panel-only application exit path.

## Candidate scope

- Oscillator, Noise, LFO, Sequencer, Delay, Audio Output, VCA, Mixer, Filter,
  and Envelope modules with Audio, Control, Gate, and Trigger routing.
- Persisted module parameters and schema-v10 placement/connection state.
- Instrument one-shots differentiated by type, theme, state, and indicator
  stage; value-driven Meter motor tone and display-driven Monitor/Panel sound.
- Dedicated production audio-module visuals for the four established themes.
- Superfine as the fifth production theme, with 10 audio and 14 non-audio
  production FBXs and prefabs using independent GUIDs.
- Global Audio controls for effects volume, instrument effects enablement, and
  modular-audio processing enablement.
- Revised Edit/Operation controller mapping, beam operation for Push Button and
  Toggle Switch, smoothed Lever/Throttle stick control, and connection-visual
  toggling while Operation mode is locked.
- Safe application exit available only by holding B for two seconds inside the
  Global Audio panel in locked Operation mode.

## Known limitations and deferred gates

- Quantitative audio-load Q1 remains deferred by product decision. No
  representative modular graph, DSP callback CPU, underrun, active-voice, or
  48/64-object audio-specific measurement is claimed as PASS.
- Superfine machine-specific triangle/material/display-width/aggregate-renderer
  caps remain REVIEW and are not adopted without Q1.
- Broader output fan-out and advanced routing semantics remain future work.
- The build uses a local debug certificate and is not a store-ready package.
- Quest 3S is outside the recorded physical-device evidence.
