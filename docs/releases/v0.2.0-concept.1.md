# AnalogInstrumentMR v0.2.0-concept.1

Release date: 2026-07-30

This is an experimental source prerelease for Meta Quest development. It is
not a store build and does not include a production signing key.

## Highlights

- Operation, Edit, and Connect modes
- 13 instrument types grouped as Meters, Indicators, Switches, and Motion
- 39 V6 visual prefabs across three original themes
- placement on any usable face of an MRUK Plane or Volume
- overlap avoidance, grid and nearby alignment, multi-object layout editing,
  target previews, directional rotation, and confirmation
- dual-controller beam/trigger operation, contact buttons, and grip-motion
  controls
- persistent Direct, Invert, Range, and Threshold connections with
  type-colored connection lines
- schema-v4 storage for up to 48 placements per Room, 192 placements across
  all Rooms, and 192 connections
- debounced runtime Current Room switching with Room UUID-scoped Spatial Anchor
  restoration

## Edit controls

- `X`: Operation → Edit → Connect
- right stick left/right: previous/next object in functional order
- right stick up/down: jump to previous/next category
- left stick left/right: change theme when no object selection is active
- right trigger: select placed object
- `A`: place or confirm move/layout
- right stick while two or more objects are selected: rotate the selection
  toward that direction around the first object
- `B`: delete an aimed unselected object, or clear the current selection
- right stick click: delete and switch the add target to the deleted type
- `Y`: reserved; no Edit-mode action in this release
- left stick click for two seconds: safe exit

Multi-object alignment and distribution use the left stick while a selection
set is active. The first selected object remains the reference.

## Operation controls

- both controller beams and triggers can operate supported controls
- lever, throttle, and power slider support grip plus controller motion
- push buttons respond to controller contact and beam plus trigger
- read-only meters and panels run subtle ambient animation
- hold left stick click for two seconds to lock or unlock `X` mode switching

## Connect controls

- select a source and target with beam plus trigger
- left stick left/right selects Direct, Invert, Range, or Threshold
- left stick click confirms an edited connection transform
- with one object selected, `A` cycles its incoming and outgoing connections
- `B` deletes the selected connection or cancels the first object selection

Range currently maps to 0.2–0.8, Threshold uses 0.5, and multiple sources
feeding one target are averaged.

## Known limitations

- Quest 3S has not been physically verified.
- Monitor numerical, graph, and shape-composition modes are not implemented.
- Connection Range and Threshold parameters are fixed rather than editable.
- Multiple connection inputs use average composition only.
- This repository retains the legacy Android identifier
  `com.DefaultCompany.MatsuMotoMeterAR` for upgrade and saved-data continuity.

## Distribution

GitHub distributes a full-source archive with Git LFS objects included. APKs
created by the project builder use local development signing and are intended
for sideload testing, not store distribution.
