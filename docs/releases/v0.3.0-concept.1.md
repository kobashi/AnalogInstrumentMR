# v0.3.0-concept.1 release candidate

Status: **draft; not tagged or published**
Candidate date: 2026-09-02

## Release goal

This pre-release candidate turns the v0.2 placement and connection baseline
into an observable and configurable signal environment. It adds dedicated
monitoring, editable connection parameters, explicit multi-input composition,
parametric graphics, a fourth production theme, and the asset-validation path
used for the 3D model brush-up.

## Candidate scope

- Four production themes with 14 instrument types each and 56 active visual
  prefabs.
- Trend Monitor with up to four color-coded input histories and an independent
  white composed-output history.
- Window Panel with four independent Energy / Balance / Phase / Detail slots
  and Orbit / Rose / Lissajous presets.
- Direct / Invert / Range / Threshold connections, including Quest-side Range
  and Threshold parameter editing.
- Average / Sum / Minimum / Maximum / Priority target composition, with
  persisted priority ranks 0 through 3.
- Placement schema v7. Migration preserves anchors, Room ownership, instrument
  state, connection transforms and parameters, Window Panel slots and presets,
  and assigns compatible composition defaults to older documents.
- Machined Ergonomics as the fourth production theme, plus the accepted meter,
  lever, toggle, control, fastener-access, and display-model refinements.
- Blender 5.2 authoring support, manifest-driven isolated candidate staging,
  Gate C promotion, visual evidence, and project-specific validation tools.
- Unity CLI / Pipeline integration for structured test, audit, render, and
  confirmation-gated Quest build commands.

## Known limitations

- Quest 3S is not physically verified.
- The 64-object run is stress characterization, not a supported placement
  count. It recorded 15 GC collections and began above the preferred 43 C
  comparison temperature.
- Quest/OpenXR GPU timing was unavailable in the recorded long-run evidence;
  the verdict uses external stability, frame pacing, delayed-frame, memory,
  thermal, and fatal-error evidence.
- Window Panel has passed live interaction and four-theme acceptance, but a
  dedicated 48 / 64 Window-Panel-only performance matrix has not been claimed.
- Safety signal processing, stale-input metadata, limiter, latched trip, and
  manual reset remain outside this candidate. The UI does not claim functional
  safety certification.
- The repository publishes source and source archives only. It does not
  distribute or support an official APK, store package, or production key.
- The ignored and untracked local Meta XR development-agent settings asset is
  present during the active development session. Its contents were not read or
  logged. The final release build must use `ConceptReleaseBuilder`, which
  temporarily quarantines this asset before build preprocessing and restores it
  afterward; a build that bypasses this path is not acceptable release evidence.
