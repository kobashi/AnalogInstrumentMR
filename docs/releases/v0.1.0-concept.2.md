# MatsuMotoMeterAR v0.1.0-concept.2

3テーマ×6種類の計器／操作部品と、global theme切り替えを統合したPrivate
プレリリース候補。Quest 3S実機検証は対象外とする。

## 操作

- 右スティック左右: 計器種類を選択
- 右スティック上下: Forge Brass / Orbital Analog / Kinetic Safetyを選択
- A: 配置
- 右スティック押し込み: 配置済み計器とSpatial Anchorを削除

themeは部屋全体のglobal設定として保存する。変更時は配置済み計器の
`VisualSocket`だけを交換し、Spatial Anchor root、UUID、pose、type ID、
InteractionColliderを維持する。未知または未保存のtheme IDはOrbital Analogへ
fallbackする。
