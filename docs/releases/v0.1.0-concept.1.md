# MatsuMotoMeterAR v0.1.0-concept.1

Meta Quest 3上でMR計器配置の技術成立性を確認するためのコンセプト確認テスト版。
製品版ではなく、開発基盤と最小垂直スライスの検証を目的とする。

## この版で確認できること

- Questのパススルー空間でアプリを起動する
- MRUKが認識した壁・床・天井へ円形Mockメーターを配置する
- Aボタンで配置し、右スティック押し込みで削除する
- Spatial Anchorへ保存し、再起動後に同じ実空間位置へ復元する
- B長押し、または終了パネルへの照準+Trigger長押しでアプリを終了する
- Quest向けURPでパススルー、HUD、MRUK roomを描画する

## 実機検証結果

- Built-in版: パススルー、controller入力、面配置、削除、Spatial Anchor保存・復元を確認
- URP版: install/start、両眼パススルー、HUD、MRUK `ROOM READY` を確認
- URP版: ピンクmaterial、黒画面、片眼欠落なし
- URP版: controller入力、照準、面配置、削除、アプリ内終了を確認
- URP版: Activity終了・再起動後、計器が同じ実空間位置へ復元することを確認
- URP版: 短時間計測で72/72 FPS、stale frame 0

## APK

リポジトリにはbuild成果物を含めない。既存APKにはローカル開発設定が
含まれた可能性があるため公開しない。トークン失効後にclean buildした
`MatsuMotoMeterAR-v0.1.0-concept.1-quest3.apk` をGitHub Release assetとして添付する。

Unityの `Tools > MatsuMotoMeterAR > Build Concept Release APK` を実行すると、
version、Android target、build sceneを検査し、Meta XRが自動生成する
DevAgent設定をRelease対象外へ隔離してから同名APKを生成する。

