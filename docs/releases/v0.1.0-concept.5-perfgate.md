# MatsuMotoMeterAR v0.1.0-concept.5-perfgate

> This is a source-only OSS release. The measured APK described below is
> retained as verification evidence and is not distributed as a release asset.

## Purpose

Quest 3で12 / 24 / 40個の描画負荷を再現し、保証点24個の10分72 Hz性能gateを
保存済みSpatial Anchorへ影響させずに実施した計測結果と、対応するOSS sourceを
記録するrelease。

## Changes

- Intent extraでのみ有効になるsynthetic performance scenario
- 6種類を均等に混在させた6列grid
- 15秒warmupと10分sampling
- 60秒smoke / 600秒full gateの計測時間指定
- 繰り返し測定向けのAPK install省略と起動PID retry
- 72 Hzの要求と実値検証
- CPU / GPU / frame time p95、遅延frame率、GC、memoryの診断log
- 測定中のHUD／heartbeat allocation停止
- 性能モード中はplacement restore、preview HUD、development exit HUDを停止
- 12 / 24 / 40以外の個数指定を拒否

## Verification

- Unity EditMode: 62 / 62 PASS
- 3テーマ×24個content budget: 既存aggregate guard PASS
- Quest 3 synthetic 24個10分72 Hz: GPU / FPS / stability / thermal / memory / GC PASS
- OVR Metrics: app GPU p95 2.310 ms、CPU utilization p95 34%、skipped 0
- Quest 3 synthetic 40個10分stress: app GPU p95 2.314 ms、CPU utilization p95 33%、
  stale / skipped / shader hitch 0
- 3テーマperformance smoke: 72 Hz維持、app GPU p95 2.302–2.317 ms
- Quest 3 normal-runtime user acceptance: PASS（`問題なし`）
- Direct app CPU time: OVR CSVでは非公開（in-app diagnostic REVIEW）
- Quest 3S: deferred

## Interpretation

アプリ内timingは`TIMING_OK`または`REVIEW`の実装診断にのみ用い、単独では
PASSを出さない。最終合否は非Development APKを使い、
OVR Metrics ToolまたはMQDH Performance Analyzerで取得したapp GPU p95、
CPU utilization、delivered frameを採用する。direct app CPU timeは取得可能なtoolを
使う場合だけp95判定へ加える。
synthetic scenarioはstatic rendering / content gateであり、通常controllerと
実Anchorのlocalization / restore負荷を完全には代替しない。厳密な24 Anchor試験は
任意とし、最終実機判定は通常runtimeのユーザー受入試験で問題がなければPASSとする。

## Quest 3 result

2026-07-23にOrbitalAnalog 24個を72 Hzで600秒実行し、43,203 sample、
delayed frame 0.019%、GC collection 0、max GC allocation 0 B、fatal 0、
45–47°Cを記録した。同一区間の公式OVR Metrics CSVは平均72.637 fps、
app GPU p95 2.310 ms、CPU utilization p95 34%、GPU utilization p95 33%、
stale 1、skipped 0、shader hitch 0だった。GPU / FPS / stability gateはPASS。
screen tear count 29は通常runtime試験で継続観察する。OVR CSVはapp CPU timeを
提供しないため、in-app CPU p95 14.264 msはvsync waitを含み得る診断値として扱う。

同日に40個stressを600秒実行し、平均72.665 fps、app GPU p95 2.314 ms、
CPU utilization p95 33%、stale / skipped / shader hitch 0、45–47°Cを記録した。
24個比でGPU p95は+0.004 msに留まった。`MockInstrumentMotion`はevent-drivenで
per-object `Update`を持たず、共有schedulerは不要である。screen tear countは45回のため、
通常runtime試験で継続観察する。

通常runtime・3 Anchor復元後の60秒baselineでもscreen tear count 5、平均72.583 fps、
app GPU p95 2.539 ms、stale / skipped / shader hitch 0だった。tearは40個stress固有の
退行ではなく、通常runtimeの約60秒目視でも裂け、段差、ずれは確認されなかった。
CSV counterは観察情報として残し、blocking issueとは扱わない。

ForgeBrassとKineticSafetyの24個・60秒smokeも72 Hzを維持し、app GPU p95は
それぞれ2.317 ms、2.302 ms、CPU utilization p95は35%、39%だった。
両テーマともstale / skipped / shader hitch、GC、fatalは0で、テーマ差による
性能退行は確認されなかった。

通常runtimeを自由使用する最終ユーザー受入では`問題なし`と報告され、
プロジェクト定義のQuest 3実機判定をPASSした。
