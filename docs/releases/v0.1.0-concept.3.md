# MatsuMotoMeterAR v0.1.0-concept.3

3テーマ×6種類の計器／操作部品へ、Quest Touch Controllerのray/direct操作を
追加したPrivateプレリリース候補。Quest 3S実機検証は対象外とする。

## 操作

- 右スティック左右: 計器種類を選択
- 右スティック上下: Forge Brass / Orbital Analog / Kinetic Safetyを選択
- A: 配置
- 右Trigger: 配置済み部品をrayまたは直接接触で操作
- 右スティック押し込み: 配置済み計器とSpatial Anchorを削除

Triggerは押下0.65／解放0.35のhysteresisを持つ。直接接触をrayより優先し、操作時は
短い右手hapticsを返す。終了パネルを狙っている間は、終了操作が計器操作より優先される。

| 種類 | 論理動作 |
| --- | --- |
| 円形メーター | 0.25ずつ進み、上限後に0へ戻る |
| レバー | 2端点を交互に切り替える |
| トグル | 2端点を交互に切り替える |
| ロータリーノブ | 1/8回転ずつ進む |
| 押しボタン | Trigger保持中だけ押下状態 |
| 状態灯 | 点灯／消灯を交互に切り替える |

論理値はthemeのvisual交換時にも維持し、Spatial Anchor復元用PlayerPrefsへ保存する。
既存のroot、UUID、pose、type ID、`VisualSocket`、`InteractionCollider`構造は維持する。
