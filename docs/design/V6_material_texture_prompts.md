## Orbital Analog

Use case: stylized-concept

Asset type: source texture sheet for a mobile VR hard-surface instrument
material atlas

Primary request: create a square, game-ready flat material texture source for
the Orbital Analog theme: precision off-white spacecraft console paint, cool
anodized aluminum, charcoal rubber gasket, and subtle cyan technical inlay.
Arrange four equal rectangular material swatches in a clean 2x2 grid with crisp
straight boundaries.

Style/medium: physically plausible PBR albedo reference, restrained premium
science-fiction cockpit hardware, fine manufacturing detail

Composition/framing: perfectly front-facing orthographic texture sheet,
material surfaces fill the canvas edge to edge

Lighting/mood: completely flat neutral illumination; no directional light, no
highlights, no shadows, no ambient occlusion

Materials/textures: very subtle powder-coat grain, fine brushed aluminum
direction, quiet rubber micrograin, extremely sparse edge-free maintenance
speckle; low contrast suitable for deriving game texture maps

Constraints: no objects, no bolts, no panels, no perspective, no bevels, no
labels, no text, no symbols, no gradients across the sheet, no cast shadows,
no watermark. Each swatch must be visually tileable and contain no unique
focal mark. Preserve clear four-zone separation.

Avoid: photorealistic product scene, dramatic weathering, rust, dirt clumps,
scratches crossing swatch boundaries, lighting baked into albedo
