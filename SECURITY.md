# Security policy

This project is an experimental source release and does not distribute an
official APK.

Please report suspected credential exposure or a security vulnerability
privately through GitHub's repository security advisory feature. Do not open a
public issue containing tokens, device identifiers, Spatial Anchor UUIDs,
keystore material, or other sensitive data.

The latest source revision is the only supported version. Quest 3 has been
tested; Quest 3S has not been physically verified.
