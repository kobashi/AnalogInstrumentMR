# Contributing

Contributions are welcome for bug fixes, documentation, tests, performance
improvements, and original instrument themes.

## Before opening a change

1. Use Unity `6000.3.19f1`.
2. Install Git LFS and run `git lfs pull`.
3. Keep generated Unity folders and local Meta credentials untracked.
4. Run the EditMode test suite.
5. Run the relevant Blender validator when changing models or textures.
6. Describe Quest hardware verification separately from Editor-only testing.

Do not commit APKs, device logs, Quest serial numbers, Spatial Anchor UUIDs,
tokens, keystores, personal filesystem paths, or `DevAgentSettings.asset`.

## Original-content requirement

Only submit code and assets you can license under this project's MIT and
CC BY 4.0 terms. Do not submit copied characters, logos, screenshots, meshes,
textures, audio, or close reproductions of identifiable third-party works.
State the source and authoring method for new assets in the pull request.

By contributing, you agree that your contribution may be distributed under
the applicable repository license.
